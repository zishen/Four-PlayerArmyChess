# FourJun 四国军棋原型

使用 Go 和 Walk 开发的 Windows 桌面四国军棋原型。当前为单机模式：用户控制下方 3 号位，其他三个席位由策略 AI 自动行棋，支持初级/中级/高级/大模型四种难度。

## 当前范围

已实现自动合法布阵、道路/铁路移动、普通棋子铁路直行与圆弧拐弯（直角路口停下）、工兵铁路全网络通行、战斗判定、行营保护、暗棋显示、席位出局和对家团队胜负，以及 AI 难度菜单、可配置的大模型对手和走子记录/保存/复盘。网络对战、手动布阵、计时和历史战绩尚未实现。

## 编译和运行

### 前置要求

- Go 1.25.x（与 `go.mod` 一致）
- Windows 操作系统

### 编译步骤

1. 下载并校验依赖：
```bash
go mod download
go mod verify
```

2. 执行检查：
```bash
go test ./...
go vet ./...
```

3. 编译程序：
```bash
go build -ldflags="-H windowsgui" -o Four-PlayerArmyChess.exe .
```

4. 保持 `ico/01-棋盘.jpeg` 位于可执行文件旁的 `ico` 目录，然后运行：
```bash
.\Four-PlayerArmyChess.exe
```

## 游戏规则

- 点击“开始游戏”后由下方 3 号位开始
- 点击己方棋子选中，再点击高亮目标位置移动
- 大吃小，同级相杀
- 工兵挖雷：工兵存活、地雷移除
- 炸弹与任何棋子同归于尽；炸弹触雷时炸弹与地雷一并消失
- 其他棋子触雷：该子消失、地雷保留
- 每一步走完后暂停约 0.5 秒，便于观察走子
- 普通棋子沿铁路可直行连续移动；仅在四个“弯道”（中央四角 (6,6)/(6,10)/(10,6)/(10,10)）处可沿其连接的相邻两方翼不停下转向，且不能直插中央；**直角路口必须停下、不可拐直角弯**；工兵可在铁路上任意拐弯（含直角）
- **铁路不能直达普通公路**：处在铁路上的棋子（含工兵）本回合只能沿铁路滑行，不能一步踏上相邻普通公路；仅可一步进入相邻行营，或一步踏上大本营所在的最外一排/列（该排是大本营唯一出口，否则任何棋子都无法夺旗）
- 大本营仅可放置军旗，且对局中不可走入
- 一队两个对家席位的军旗均被夺取时，另一队获胜
- 对家（对角席位）互为队友，紧邻席位互为对手；不能进入或吃掉队友棋子所在点
- 占领（吃掉）对方军旗的棋子停在原地，之后不能再移动
- 一方司令阵亡（被炸、触雷或与对方司令同归于尽）后，该方军旗位置对外公开

规则资料与当前图片棋盘存在待确认差异，详见 [项目问题清单](doc/issues.md)。

## AI 与难度

- 菜单「难度」可选择：初级 / 中级 / 高级 / 大模型。
- 初级保守、中级均衡、高级会主动进攻、保护军旗并配合队友；三档均为本地启发式 AI，会优先吃子、向敌方大本营推进。
- 「大模型」难度通过 OpenAI 兼容接口调用外部大模型决策。菜单「设置 → 大模型设置…」填写接口地址、API Key 和模型名称，配置保存在可执行文件旁的 `ai_config.json`；未配置或调用失败时自动回退到高级 AI。
- 也可用环境变量 `FOURJUN_LLM_URL` / `FOURJUN_LLM_KEY` / `FOURJUN_LLM_MODEL` 配置。

## 走子记录与复盘

- 对局中右侧“走子记录”列表会逐步记录每一步（席位、起止坐标、公开结果文本）。
- 对局结束会自动保存一份记录到可执行文件旁的 `对局_日期时间.4gj`；也可随时点击“保存对局”另存。
- 点击“打开复盘”载入 `.4gj` 文件即可复盘：**复盘时四方棋子的类型全部公开**，可用“上一步 / 下一步 / 自动播放 / 退出复盘”逐回合查看，右侧列表点击任意一步可直接跳转。
- 记录文件为 JSON（`.4gj`），保存了**初始布阵（含各棋子类型）+ 每一步走法**，因此可完整重放；复盘重现使用游戏自身的走子规则，保证与对局一致。
